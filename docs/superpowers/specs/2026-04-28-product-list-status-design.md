# 商品列表状态展示与操作调整设计

## 目标

调整门店管理系统商品列表中的状态字段与行操作，满足以下要求：

- 列表中的“可售状态”“上架状态”改为只读状态展示，不直接操作
- 删除“销售状态”“销售店铺”两列
- 将“设为可售 / 设为不可售”和“上架 / 下架”收敛到操作列
- 商品处于“不可售”时，点击上下架统一提示“请先将商品设为可售状态”
- 相关列宽收窄，减少表格横向占用

## 方案

### 列表展示

- “可售状态”列使用标签展示“可售 / 不可售”
- “上架状态”列使用标签展示“已上架 / 已下架”
- 删除“销售状态”“销售店铺”列，不再在列表中展示对应统计

### 行操作

- 根据当前商品可售状态，展示“设为可售”或“设为不可售”
- 根据当前商品上下架状态，展示“上架”或“下架”
- 操作列最多直出 3 个动作，超出部分统一收进“更多”下拉菜单
- 保留现有详情、编辑、复制、本店设置、SKU 管理、库存、分享等操作

### 业务约束

- “设为可售 / 设为不可售”继续复用现有店铺发布接口
- “上架 / 下架”继续复用现有商品/店铺渠道状态更新接口
- 当商品为“不可售”时，行级上下架操作前先拦截并提示“请先将商品设为可售状态”

## 验证

- 列表只展示状态，不出现状态开关
- 操作列可根据当前状态切换按钮文案
- 当操作数超过 3 个时，仅前 3 个直接展示，其余通过“更多”访问
- 不可售商品点击上下架时不落库，只出现指定提示
- 表格横向宽度较改动前收窄
