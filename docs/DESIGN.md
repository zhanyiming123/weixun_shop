# DESIGN.md

## 设计原则（Lite）

1. 页面不承载核心业务规则，核心规则放在 `services`
2. 数据读写统一由 `repositories` 负责
3. 可复用格式化与错误模型放在 `lib`
4. 新增能力优先写类型，再写实现

## 错误处理

- 业务层抛 `AppError`
- 页面层统一转为 `Message.error` 等用户提示

## 公共能力

- 金额展示统一使用 `src/lib/format.ts` 的 `formatCurrency`
- 禁止在页面中重复实现同类格式化函数

## 列表页规范

- 规范适用范围：后续所有列表页
- 列表页不展示页面头部描述区（标题/说明型 Hero 区）
- 二级及以下页面必须通过路由配置提供面包屑导航

## 页面说明规范

- 规范适用范围：后续所有新建页面（含首页）
- 页面不展示页面头部说明区（标题/说明型 Hero 区）

## 表单配置规范

- 表单配置项标题与配置组件必须在同一行展示
- 必填配置项在标题前显示红色 `*`
- 非必填配置项不显示 `*`
- 单选配置项优先使用标准 `Radio`（radio button）形式，不使用按钮式分段单选

## 门店人员管理（新增员工来源）

- 新增员工提供两个来源：`从商户组织添加`、`外部导入`
- `从商户组织添加`：从商户组织架构圈选人员
- `外部导入`：支持在线创建单人；支持下载员工模板并进入批量导入交互流程
