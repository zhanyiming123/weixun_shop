# 上海唯寻教育科技有限公司

## 快速开始

```bash
# 初始化项目
npm install

# 开发模式
npm run dev

# 构建
npm run build
```

## 工程基线（agents-lite）

- 项目导航：`AGENTS.md`
- 架构约束：`ARCHITECTURE.md`
- 规范与计划：`docs/DESIGN.md`、`docs/PLANS.md`

## 本地检查

```bash
# 类型检查
npm run typecheck

# 架构依赖检查
npm run check:arch

# ESLint（当前脚本会自动修复）
npm run eslint
```
